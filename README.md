# Fala Comigo

Prancha de comunicação alternativa (CAA) para crianças não verbais, feita para uso em
terapia ocupacional. Abre com dois botões grandes — SIM e NÃO — que falam a palavra em
português usando a voz do próprio aparelho.

- Arraste para o lado para trocar de prancha.
- Segure o botão ⚙ por 1 segundo para editar: criar pranchas, adicionar botões, escolher
  cor, emoji, o texto falado, a voz e a velocidade da fala.
- Tudo fica salvo no próprio aparelho e funciona sem internet depois de instalado.

## Instalar no iPhone

Abrir o site no Safari › botão Compartilhar › **Adicionar à Tela de Início**.

## Estrutura

Tudo em um arquivo: `index.html`. Sem build, sem dependências.
